# FoodieBot – Food Recommendation and Ordering Chatbot

## 📌 Description

FoodieBot is a Python-based chatbot application that helps users
choose food, view the menu, order food, manage their cart and
place an order.

## ✨ Features

- 🍴 Food recommendations
- 📋 View food menu
- 🛒 Order food
- 🧾 Cart management
- 💰 Total amount calculation
- ✅ Order confirmation
- ❌ Input validation

## 🛠️ Technologies Used

- Python
- Dictionaries
- Loops
- Conditional Statements
- Exception Handling

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python foodie_bot.py
